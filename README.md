# TailorPro
TailorPro est une application de gestion des salons de couture professionnels. il prend en compte la gestion du fichier client, la prise des mensures, l'intégration du devis, le paiement en acompte ou en totalité, la notification de rappel au client, les statistiques clients ainsi que le bilan financier. il integre egalement la gestion des employes
